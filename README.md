# Blood Bank Management System

## Project Description
The Blood Bank Management System is a Java Servlet and MySQL-based web application designed to manage blood donors, receivers, and blood inventory.

## Features
- Donor Registration
- Receiver Registration
- Blood Group Matching
- Blood Inventory Management
- Blood Issue History
- Transaction Confirmation

## Technologies Used
- Java
- Java Servlets
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat
- Maven
